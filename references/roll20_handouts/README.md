# Roll20 Handout References

This folder contains Markdown exports from Duncan's Roll20 handouts for use as
reference material while updating simulator data.

Notes:

- Source was a live Roll20 DOM dump, converted to Markdown outside this repo.
- Raw browser/DOM output is intentionally not included.
- `Player Notes` was intentionally excluded because it is campaign-note material,
  not rules reference material.
- Roll20 object IDs are preserved in filenames to make it easier to trace a file
  back to the source handout.
- Some handouts appear twice where Roll20 has separate race and racial-talent
  pages with the same visible name.
